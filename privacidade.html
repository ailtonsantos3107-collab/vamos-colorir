Política de Privacidade

Esta política vale para o aplicativo usado pelo canal infantil @modernooff1273 no YouTube.

O que o aplicativo faz

O aplicativo usa a API do YouTube apenas para enviar os vídeos do próprio canal (permissão youtube.upload). Ele é usado somente pelo dono do canal.

Dados de usuários

O aplicativo não coleta, não guarda e não compartilha dados de pessoas que assistem aos vídeos, nem de crianças. Não usa anúncios próprios, formulários, cookies ou rastreamento. Os vídeos são marcados como "conteúdo para crianças" no YouTube, conforme as regras da plataforma.

Serviços do Google

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google. Assistir aos vídeos no YouTube segue a Política de Privacidade do Google.
